# 📚 Documentation - Tailwind Smart Plugin

Bienvenue dans la documentation complète du **Tailwind Smart Plugin** ! Ce plugin révolutionnaire transforme votre expérience de développement Tailwind CSS dans IntelliJ IDEA.

## 🚀 Démarrage Rapide

### Installation
1. Ouvrir IntelliJ IDEA
2. Aller dans **Settings > Plugins**
3. Rechercher "Tailwind Smart Plugin"
4. Installer et redémarrer

### Première Utilisation
1. Ouvrir un fichier HTML/JSX/TSX
2. Taper `class="` dans un élément
3. Voir les suggestions intelligentes apparaître !

## 🎯 Raccourcis Clavier

| Raccourci | Action |
|-----------|--------|
| `Shift+F7` | Trier les classes sélectionnées |
| `Shift+Alt+F7` | Trier toutes les classes du fichier |
| `Shift+F8` | Basculer le pliage des classes |
| `Shift+Alt+F8` | Plier toutes les classes |
| `Shift+Ctrl+F8` | Déplier toutes les classes |

## 🛠️ Configuration

### Configuration Automatique
Le plugin détecte automatiquement :
- `tailwind.config.js` dans la racine du projet
- Classes personnalisées et thèmes
- Configuration des frameworks

### Configuration Manuelle
1. Aller dans **Settings > Tailwind Smart Plugin**
2. Configurer les préférences
3. Activer/désactiver les fonctionnalités
4. Configurer l'intégration Figma

### FAQ
- **Q: Les suggestions ne s'affichent pas ?**
  A: Vérifiez que `tailwind.config.js` est présent dans votre projet

- **Q: Le plugin ralentit l'IDE ?**
  A: Désactivez temporairement certaines fonctionnalités dans les paramètres

- **Q: Comment utiliser l'intégration Figma ?**
  A: Configurez votre token d'accès Figma dans les paramètres du plugin
