IA Contextuelle

Suggestions intelligentes basées sur le contexte DOM. Le plugin détecte automatiquement le type de composant et propose les classes les plus pertinentes.

  • • 50+ patterns UI prédéfinis
  • • Apprentissage des préférences

Preview Visuel

Rendu CSS en temps réel dans l'éditeur. Voir instantanément le résultat de vos classes Tailwind sans quitter votre IDE.

  • • Aperçu temps réel

  • • Outils visuels

  • • Import de design tokens
  • • Génération de design system
